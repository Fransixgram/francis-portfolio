Notes from building

ENGINEERING NOTES

A few lessons and decisions from the applications featured in this portfolio.

Cosmo Mobile Spares

Design around the buying journey

Category browsing, product pages, cart, and delivery choices should help a shopper understand the next step toward checkout.

Storefronts

Keep product details consistent

Category lists, detail pages, carts, and admin tools work better when they use the same underlying product information.

Node-Store

Give API routes clear roles

Separating authentication, user, admin, and product routes makes each request path easier to follow.

Smart Todo Dashboard

Use browser storage for small tools

Local storage keeps tasks after refresh for one browser, while making clear it does not sync across user accounts or devices.
